 # 🎤 Interview Simulator (Python)

A **Python-based Interview Simulator** designed to help users practice interview questions in an interactive manner.  
The application simulates a real interview environment by asking questions and evaluating user responses.

---

## 📌 Project Overview

The Interview Simulator is a console-based Python application that:
- Asks predefined interview questions
- Takes user input as answers
- Provides feedback or scoring
- Helps users prepare for technical and HR interviews

This project focuses on **logic building, Python fundamentals, and user interaction**.

---

## 🚀 Features

- Interactive question–answer system  
- Technical & HR interview questions  
- User-friendly console interface  
- Score / feedback generation  
- Easy to extend with new questions  

---

## 🛠️ Tech Stack

- **Python 3**
- Standard Python Libraries

---


---

## ⚙️ How It Works

1. The program starts the interview session  
2. Questions are displayed one by one  
3. User enters answers via keyboard  
4. Responses are evaluated  
5. Final score / feedback is shown
